# 💎 Bubble Gem Storm

**Bubble Gem Storm** is a colourful, level-based arcade game built with **Flutter and Dart**. Players progress through increasingly challenging stages by interacting with different types of gems, completing level objectives, and earning stars.

## ✨ Features

- **110 Levels** across 3 difficulty tiers.
- **8 Unique Gem Types** with different gameplay behaviours.
- **Dynamic Gameplay** with real-time gem spawning and movement.
- **Configurable Levels** with adjustable spawn rates, difficulty, objectives, and scoring.
- **Star-Based Rating System** to reward player performance.
- **Audio and Visual Effects** for an engaging gaming experience.
- **Firebase Integration** for authentication and cloud-backed game data.
- **Crash Reporting and Analytics** using Firebase services.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK 3.8.1 or later
- Android Studio or VS Code
- Android emulator or physical device
- Firebase project

### Installation

**1. Clone the repository**

\`\`\`bash
git clone https://github.com/SanaShaikh2191/Bubble-Gem-Storm.git
cd Bubble-Gem-Storm
\`\`\`

**2. Install dependencies**

\`\`\`bash
flutter pub get
\`\`\`

**3. Configure Firebase**

- Create a project in the Firebase Console.
- Register your Android application.
- Configure Firebase using FlutterFire CLI.

\`\`\`bash
dart pub global activate flutterfire_cli
flutterfire configure
\`\`\`

Ensure that the generated Firebase configuration is available in the project.

**4. Run the application**

\`\`\`bash
flutter run
\`\`\`
